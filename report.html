Vitals, risk levels, and where they disagree

This report works through the six IoT-monitored vitals in the maternal health risk cohort: age, systolic and diastolic blood pressure, blood glucose (BS), body temperature, and heart rate, against the clinician-assigned risk level (low / mid / high). Code for every table and figure below is folded by default; click Code to expand it.

Data quality flags

A few things in this dataset are worth flagging before we trust any number above too far. We have not removed any of these rows in this report or in the risk explorer. The point here is to name what is odd and be upfront that we do not know, from the data alone, whether it reflects genuine repeat measurements, coincidence, data-entry duplication, or sensor error.

Only 452 of the 1014 records are unique row for row. The other 562 are exact repeats: same age, same blood pressure, same glucose, same heart rate, same risk label, of a combination that already appears elsewhere, spread across 304 distinct value combinations that each show up more than once (the most repeated single combination appears 27 times). That is over half the dataset. We are leaving every row in, because deleting them assumes they are errors, and they might not be. IoT sensors reading the same patient repeatedly, or several patients genuinely sharing similar vitals, would produce the same pattern. It does mean every mean, SD, and correlation in this report implicitly treats a handful of repeated value combinations as if they were independent patients. This is worth keeping in mind when reading the risk-level split above: the proportions shift noticeably, low risk goes from a plurality to closer to half the cohort, once we collapse to unique rows only.

n_age_under15 = sum(maternal_df$age < 15)

n_hr_under40  = sum(maternal_df$heart_rate < 40)

Age ranges from 10 to 70 years. 54 records list an age under 15, and 193 are under 18, roughly 19% of the cohort. This dataset was collected across hospitals and community clinics in a setting where adolescent pregnancy is a documented public health pattern, so we are not treating the under-18 group as an error. If anything, it is a subgroup worth its own look rather than folding into one continuous age trend. The upper end is harder to explain the same way. 45 records list an age past 55, including some close to 70, past the point pregnancy is possible without medical intervention. We treat that as a more likely candidate for a recording error, but again flag it rather than drop it.

The separation is clearest for blood glucose and blood pressure. High-risk pregnancies carry a mean BS of 12.1 mmol/L against 7.2 mmol/L for low-risk pregnancies, a gap that swamps the within-group spread for the low-risk group (SD well under 1 mmol/L there, per the table above). Systolic and diastolic blood pressure move together in the same direction: 124/85 mmHg on average for high-risk pregnancies versus 106/73 mmHg for low-risk ones. Age shows a real but noisier gradient. High-risk pregnancies skew roughly 9 years older on average than low-risk ones, with substantial overlap in both directions. Body temperature and heart rate barely move across groups, which is consistent with them acting more as flags for acute events (fever, tachycardia) than as steady discriminators of risk class in this cohort.

Systolic and diastolic blood pressure are, unsurprisingly, the strongest pair in the matrix (r = 0.79), since they measure the same physiological event from two ends. Age correlates moderately with blood pressure and glucose alike (r in the 0.4 to 0.47 range), which tracks with the age gradient seen in the boxplots above. Heart rate stands apart. Its strongest correlation with anything else in the matrix is 0.14, weak enough that it is carrying mostly independent information, or mostly noise, relative to the other five vitals.

A simple risk classifier

As a baseline read on how separable the three risk levels actually are from the six vitals, we fit a multinomial logistic regression on 760 randomly sampled records and evaluated it on the held-out 254. This is the same modeling approach behind the risk explorer’s comparison logic, formalized here with a train and test split. We standardize each vital to a common scale (mean 0, SD 1, using the training set’s own mean and SD) before fitting, so the coefficients below are comparable to each other regardless of the units the underlying vital happens to be measured in.

set.seed(2026)

split_idx = sample(seq_len(nrow(maternal_df)), size = round(0.75 * nrow(maternal_df)))
train_df  = maternal_df[split_idx, ]
test_df   = maternal_df[-split_idx, ]

scale_vars  = c("age", "systolic_bp", "diastolic_bp", "bs", "body_temp", "heart_rate")
train_means = sapply(train_df[scale_vars], mean)
train_sds   = sapply(train_df[scale_vars], sd)

standardize_df = function(df) {
  for (v in scale_vars) df[[v]] = (df[[v]] - train_means[[v]]) / train_sds[[v]]
  df
}

train_std = standardize_df(train_df)
test_std  = standardize_df(test_df)

fit = multinom(
  risk_level ~ age + systolic_bp + diastolic_bp + bs + body_temp + heart_rate,
  data = train_std, trace = FALSE
)

pred = predict(fit, newdata = test_std)
acc  = mean(pred == test_df$risk_level)
conf_df = tibble(Predicted = pred, Actual = test_df$risk_level) |>
  count(Predicted, Actual, name = "n") |>
  complete(Predicted = levels(test_df$risk_level), Actual = levels(test_df$risk_level), fill = list(n = 0)) |>
  mutate(label_color = if_else(n > max(n) * 0.55, "white", "#1c2430"))

p4 = conf_df |>
  ggplot(aes(x = Actual, y = Predicted, fill = n,
             text = paste0("Predicted ", Predicted, ", actual ", Actual, ": ", n))) +
  geom_tile(color = "#f6f7fb", linewidth = 1.2) +
  geom_text(aes(label = n, color = label_color), fontface = "bold", size = 4) +
  scale_color_identity() +
  scale_fill_gradient(low = "#fbeef8", high = "#7a1f6e") +
  labs(x = "Actual", y = "Predicted", title = "Confusion matrix: predicted vs. actual risk level", fill = "Count")

ggplotly(p4, tooltip = "text")

Held-out accuracy is 61.4%, against a 43.7% baseline for always predicting the majority class in the test fold. The darkest cells above sit on the diagonal, which is where predicted and actual risk level agree; the confusion matrix shows where the model actually struggles. Mid-risk pregnancies are the hardest to separate cleanly, which lines up with the boxplots: mid-risk vitals sit between the low- and high-risk groups on almost every variable, rather than forming a distinct cluster of their own.

The model is fit with low risk as the reference category, since it is the first level of risk_level. Every coefficient below is therefore relative to a low-risk pregnancy: a positive estimate means that vital, holding the others fixed, pulls the classification away from low risk and toward mid or high risk, and a negative one pulls back toward low risk. Rows are grouped by vital, high risk above mid risk, so the two effects for a given vital sit next to each other.
